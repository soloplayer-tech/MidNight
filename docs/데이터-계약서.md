# Unframed — 언리얼용 데이터 계약서 (Data Contract)

> 언리얼팀(박재현·임효택)은 API 통신 자체보다 **JSON 데이터 모양**에 집중하면 된다.
> 이 문서는 "언리얼이 읽을/받을 JSON이 어떤 모양인가"를 정의한다.
>
> **SSOT는 `docs/명세서/Unframed_API명세서.xlsx`.** 아래 필드명은 그 엑셀과 일치시킨 것이며, 충돌 시 **엑셀이 우선**한다.
>
> **핵심 규칙: 백엔드가 주는 JSON == 언리얼이 읽는 JSON.** 처음엔 로컬 JSON(`docs/data/*.json`)을 읽고,
> 백엔드 완성 후 "파일 읽던 자리를 서버 호출로 교체"만 한다(게임 로직 무변경).

> ⚠️ **미확정**: 언리얼팀이 C++ `USTRUCT`를 쓸지 Blueprint 구조체를 쓸지 (`CLAUDE.md` §11). 아래는 C++ 기준 예시.

## 식별자

- `paintingId` = 명화 외부 식별자(예: `mona_lisa`, `the_scream`, `starry_night`). 사람이 읽는 ID이며 DB PK와는 분리.
- `playerId`, `sessionId`, `quizId` 도 모두 문자열 ID.

## Painting (명화 데이터 모델 — 엑셀 Data Models와 동일)

| 필드 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `paintingId` | string | Y | 명화 고유 ID (예: `mona_lisa`) |
| `title` | string | Y | 작품명 (예: 모나리자) |
| `artist` | string | Y | 작가 |
| `era` | string | N | 시대/사조 |
| `personaPrompt` | string | Y | AI 시스템 프롬프트(서버 전용; 클라이언트엔 노출 안 할 수 있음) |
| `assetKey` | string | N | 언리얼 에셋 매핑 키 — **복제 시 교체 지점**(뭉크·반 고흐는 이 값만 바꿈) |

## 언리얼이 화면에 쓰는 주요 응답 모양

게임 한 사이클에서 언리얼이 받는 응답(엑셀 Detail 시트 기준):

- **포획** `POST /captures` → `{ captured, paintingId, greeting, greetingTtsUrl }`
- **대화** `POST /paintings/{paintingId}/chat` → `{ reply, ttsUrl, turnCount, quizReady }`
  - `quizReady=true` 가 되면 퀴즈 버튼 활성화 (예: 2턴 이상)
- **퀴즈** `POST /paintings/{paintingId}/quiz` → `{ quizId, question, choices[] }`
  - ⚠️ `answerIndex`는 **서버만 보관**, 클라엔 안 줄 수 있음. 정답 판정은 `/seal`에서.
- **봉인** `POST /paintings/{paintingId}/seal` → `{ correct, sealed, stampCount, totalStamps, feedback }`
- **세션 시작** `POST /sessions` → `{ sessionId, targets[], totalStamps }`

전체 엔드포인트·필드는 `docs/API-아키텍처.md` 및 엑셀 참고.

## 언리얼 USTRUCT 매핑 (C++ 선택 시 예시)

`FJsonObjectConverter`로 JSON↔구조체 자동 변환. **필드명이 정확히 일치**해야 자동으로 꽂힌다.
(UE는 보통 PascalCase 프로퍼티 ↔ camelCase JSON 키를 매칭: `PaintingId`↔`paintingId`. 팀에서 1회 검증할 것.)

```cpp
USTRUCT(BlueprintType)
struct FPaintingData
{
    GENERATED_BODY()
    UPROPERTY(BlueprintReadOnly) FString PaintingId;
    UPROPERTY(BlueprintReadOnly) FString Title;
    UPROPERTY(BlueprintReadOnly) FString Artist;
    UPROPERTY(BlueprintReadOnly) FString Era;
    UPROPERTY(BlueprintReadOnly) FString AssetKey;
    // personaPrompt 는 보통 서버 전용이라 클라 구조체에 안 둠
};

USTRUCT(BlueprintType)
struct FChatResponse
{
    GENERATED_BODY()
    UPROPERTY(BlueprintReadOnly) FString Reply;
    UPROPERTY(BlueprintReadOnly) FString TtsUrl;
    UPROPERTY(BlueprintReadOnly) int32 TurnCount = 0;
    UPROPERTY(BlueprintReadOnly) bool bQuizReady = false; // JSON: quizReady
};

USTRUCT(BlueprintType)
struct FQuizResponse
{
    GENERATED_BODY()
    UPROPERTY(BlueprintReadOnly) FString QuizId;
    UPROPERTY(BlueprintReadOnly) FString Question;
    UPROPERTY(BlueprintReadOnly) TArray<FString> Choices;
};

USTRUCT(BlueprintType)
struct FSealResponse
{
    GENERATED_BODY()
    UPROPERTY(BlueprintReadOnly) bool bCorrect = false;   // JSON: correct
    UPROPERTY(BlueprintReadOnly) bool bSealed = false;    // JSON: sealed
    UPROPERTY(BlueprintReadOnly) int32 StampCount = 0;
    UPROPERTY(BlueprintReadOnly) int32 TotalStamps = 0;
    UPROPERTY(BlueprintReadOnly) FString Feedback;
};
```
> 주의: `bool b...` 프로퍼티는 JSON 키와 자동 매칭이 안 될 수 있어 변환 검증 필요. 안 되면 `correct`/`sealed` 그대로 `bool Correct;` 식으로 두거나 커스텀 파싱.

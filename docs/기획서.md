# Unframed — 기획서

> 자정의 미술관에 빨려든 학생이, 액자에서 탈출한 명화를 카메라로 포획하고
> 대화·퀴즈로 다시 봉인하는 PC 1인칭 교육 게임.
> 슬로건: **"틀을 벗어난 명화를, 다시 틀로. 설명하지 않는 미술관."**

## 1. 팀 개요

- 팀명: **Unframed** (12팀) / 멘토: 이철우 강사
- 과제: 과제 2 「유니티·언리얼을 활용한 교육 콘텐츠 개발 (AI 활용)」 — ㈜디아리움

## 2. 프로젝트명

- **Unframed** — 부제: 자정의 미술관에서 펼쳐지는 명화 포획 교육 게임
- 이름값: `un-frame`(액자 밖으로 탈출한 명화) ↔ `re-frame`(다시 봉인). 문제 상황 자체가 제목.
  "틀에 박힌 수업의 틀을 깬 새로운 미술 교육"이라는 중의적 메시지.

## 3. 프로젝트 소개

- **문제**: 미술 교육이 일방적·암기식이라 지루함.
- **해결**: 직접 탐색·대화·평가하는 능동적 학습 게임.
- **핵심 경험(게임 루프)**:
  ```
  탐색 → 포획(찰칵) → 명화 설명(2d 인터렉티브 -> 버추얼휴먼은 시간 남으면) -> TTS → 자유 대화
        → 대화 기반 퀴즈 → 정답 시 봉인 → 스탬프 수집
  ```
- 목표: 3종(모나리자·뭉크·반 고흐) 전부 봉인 → 교실 복귀.

### 스토리 (1인칭 POV)

모나리자 관련 미술 수업이 진행 중-> 지루하던 학생이 책 속으로 빨려 들어감 → 미술관 랜딩 →
빈 액자(모나리자)와 둥둥 떠다니는 인물 발견 → 인벤토리에 카메라 + 스탬프 3칸 종이 →
카메라로 포획 → 액자 인터랙트로 봉인 → 화면 전환 → 명화가 버추얼 휴먼으로 등장해 TTS 강의 →
그 후 추가로 궁금한 점 질의응답 -> 유저와 대화가 끝나면 설명한 내용 + 질의응답 내용 정리해 퀴즈로 생성 ->
퀴즈를 다 맞추게 되면 스탬프에 도장이 찍히며 이펙트와 함께 반투명 인물이 명화에 봉인되며 원래 버전의 명화가 생성 ->
3개 모두 봉인 시 강의실로 복귀. ->
선생님이 갑자기 질의응답 나눈 내용 중 모나리자에 관한 디테일한 내용을 졸고있던 학생에게 물어봄 ->
학생이 정답을 맞추게 됨

## 4. UX 원칙 — "설명하지 않는다, 환경이 말하게 한다"

환경 스토리텔링 / 디제시스 UI. 튜토리얼 텍스트 없이 환경이 곧 설명.

| 환경 요소 | 유저가 스스로 깨닫는 것 |
|---|---|
| 빈 액자 | "여기 뭔가 있어야 하는데 없다" → 목표 인식 |
| 둥둥 떠다니는 인물 | "쟤가 저기서 빠져나왔구나" → 원인-결과 |
| 인벤토리의 카메라 | 도구 용도 자가발견 |
| 스탬프 3칸 종이 | 진행도/목표량을 UI 아닌 소품으로 |
| 채워지는 스탬프 | 진척 피드백(프로그레스 바 대신) |

**안전장치(넛지)**: 떠다니는 명화가 빈 액자 근처 맴돌기 / 뷰파인더에 대상 들어오면 반짝 / 스탬프 첫 칸 흐릿한 가이드 — 길은 안 잃게.

## 5. 팀 구성 및 역할 (융합성의 증거)

- **AI (김정현)**: 명화 버추얼휴먼(V2) — 시스템 프롬프트로 가둔 작품 한정 대화 + 대화 기반 퀴즈 생성.
- **백엔드 (최준환)**: 도감·진척 서버 — 봉인 성공/실패, 학습 완료율, 정답률, 플레이 시간, 명화 도감, 재방문 복원 + AI 중계.
- **TA (남창헌)**: 봉인 물감 흡수 셰이더 + 에셋 작업 + 루멘 라이팅 + 유령 반투명 머티리얼.
- **언리얼 (박재현·임효택)**: 1인칭 탐색, 카메라 포획, 액자 인터랙트·화면전환, 빌드 통합.

## 6. 세부 추진 내용

1. **개발배경·목적**: 능동적 미술 교육 + 게임 몰입 결합.
2. **개발환경·언어**: Unreal Engine 5.7 (C++/Blueprint), 생성형 AI API(+TTS), 백엔드 서버·DB.
3. **시스템 구성·아키텍처**: 클라이언트(언리얼) ↔ 백엔드 서버 ↔ 생성형 AI API. (b) 백엔드 중계. → `docs/API-아키텍처.md`
4. **주요 기능**: 포획 / 버추얼휴먼 대화 / 동적 퀴즈 봉인 / 도감·진척 저장 / 디제시스 UI.
5. **기대효과·활용분야**: 미술관·학교 교육 콘텐츠, 명화 교체로 무한 확장.
6. **기타**: 디자인 원칙 "설명하지 않는다, 환경이 말하게 한다".

## 7. 생성형 AI 활용

- 명화별 페르소나 대화(시스템 프롬프트 제약) + 대화 맥락 기반 실시간 퀴즈 생성.
- **차별점**: AI 대화가 장식이 아니라 게임 진행의 **필수 관문**(대화해야 퀴즈가 나옴).

## 8. 개발 범위 / 일정

- **MVP**: 모나리자 1종 풀 동작 → 뭉크·반 고흐는 에셋 교체로 복제.
- **데모 전략**: 봉인 퀴즈는 로컬 JSON으로 안전 동작, AI 자유 대화는 30초 녹화 폴백. 데이터 소스는 서버↔로컬 스위치로 전환.
